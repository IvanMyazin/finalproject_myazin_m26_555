# ValutaTrade Hub

Учебное консольное приложение, которое имитирует работу валютного кошелька.
Пользователь сможет управлять виртуальным портфелем фиатных и криптовалют,
совершать сделки и просматривать актуальные курсы.

## Технологии

- Python 3.12;
- `uv` для зависимостей и сборки пакета;
- `ruff` для проверки и форматирования кода;
- `prettytable` для вывода таблиц в консоли;
- JSON-файлы для хранения учебных данных.

## Подготовка окружения

```bash
uv sync
```

## Запуск

```bash
uv run valutatrade-hub
```

Приложение откроет интерактивную сессию. После `login` в этой же сессии доступны
операции с портфелем:

```text
register --username alice --password 1234
login --username alice --password 1234
show-portfolio --base USD
buy --currency BTC --amount 0.05
sell --currency BTC --amount 0.01
get-rate --from BTC --to USD
```

Команда `help` показывает доступные команды, `exit` завершает приложение.

## Конфигурация

Настройки находятся в секции `[tool.valutatrade]` файла `pyproject.toml`:

- `data_dir`, `users_file`, `portfolios_file`, `rates_file` — пути к данным;
- `rates_ttl_seconds` — срок свежести курса в секундах;
- `default_base_currency` — базовая валюта по умолчанию;
- `logs_dir`, `log_file`, `log_format`, `log_level` — параметры логирования;
- `log_max_bytes`, `log_backup_count` — размер файла и число резервных копий.

Настройки загружает Singleton `SettingsLoader`. Метод `get()` возвращает значение,
а `reload()` повторно читает конфигурацию из `pyproject.toml`.

Доступ к JSON-файлам выполняется через Singleton `DatabaseManager`. Изменяющие
операции проходят под одной блокировкой как цикл «чтение → изменение → запись».

Операции `buy(user_id, currency_code, amount)` и
`sell(user_id, currency_code, amount)` проверяют пользователя текущей сессии и
получают валюту через фабрику `get_currency()`. Метод `get_rate()` возвращает курс
вместе с `updated_at` и использует настроенный TTL кеша.

## Логирование операций

Методы `buy()` и `sell()` отмечены декоратором `@log_action`. Записи сохраняются
в человекочитаемом формате в `logs/actions.log`. Для каждого действия фиксируются
время, пользователь, валюта, сумма, курс, базовая валюта и результат. При ошибке
добавляются тип и текст исключения, после чего исключение передаётся в CLI.

Файл ротируется при достижении 1 МБ; сохраняются три резервные копии. Базовый
уровень — `INFO`, для отладки в конфигурации можно установить `DEBUG`.

## Ошибки команд

- `sell`: при недостаточном балансе показываются доступная и требуемая суммы.
- `get-rate`, `buy`, `sell`, `show-portfolio`: неизвестный код валюты вызывает
  сообщение с подсказкой `help get-rate` и списком поддерживаемых валют.
- При недоступности сервиса курсов приложение предлагает повторить запрос позже
  или проверить сеть.
